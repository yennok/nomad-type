Inter Hebrew, a Hebrew companion to the Inter typeface, variable weight 100 to 900, designed by Nir Zabari Yenni for Nomad Type

A Hebrew companion to Inter. It is drawn on Inter's own metric frame, the same units per em, cap height, x-height and vertical metrics, so Hebrew and Latin can be set together on one line with no size or baseline compensation. One variable weight axis runs from 100 to 900 with the same named instances as Inter. The Hebrew covers the alphabet, the five final forms and all seventeen nikud marks with mark positioning, so vocalised text holds together at reading size. Figures and punctuation on this page come from Inter.

Still to come: an italic, and an optical size axis to match Inter’s own. The upright weights are finished, and they are what this page shows.
