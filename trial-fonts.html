What's included in trial fonts?

Our trial fonts include:

  • Complete character sets for Hebrew, Arabic, and/or Latin scripts
  • Multiple weights and styles where available
  • OpenType features and language support

Trial fonts are perfect for testing layout, readability, and overall design integration before committing to a full license.

How to use trial fonts

After downloading, install the fonts on your system and use them in your design applications. Trial fonts function exactly like licensed fonts, with the only difference being a built-in indicator that identifies them as trial versions.

Remember that trial fonts are intended for evaluation purposes only. For final production or commercial use, you will need to purchase the appropriate license. Students may use trial fonts for academic work, while commercial use still requires a valid license.
