Licensing

Desktop License

Perfect for print design, branding, and offline use in design tools.

  • Licensed by number of users: Individual, Studio (up to 5 users), or Company
  • Install on up to 2 devices per licensed user
  • Use in print and digital publications
  • Create logos and branding materials
  • Include fonts in static client presentations
  • Excludes embedding in websites, apps, or software products

Web License

For websites and web apps using self‑hosted fonts or @font-face.

  • Licensed by number of users: Individual, Studio (up to 5 users), or Company
  • Unlimited page views, no tracking required
  • Covers all domains owned by the licensee, for a single brand
  • Fonts provided in WOFF/WOFF2 formats
  • Self-hosting only (no third-party CDN services)
  • Excludes desktop and app installation rights

App License

For embedding fonts in mobile or desktop applications.

  • Licensed per app title (includes all versions and platforms)
  • Embed in iOS, Android, macOS, and Windows apps
  • Unlimited downloads and updates
  • Source code protection required
  • Excludes use in branding, print, or websites
